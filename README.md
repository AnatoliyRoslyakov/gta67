# Малый квартал · 4

[Открыть квартал](https://anatoliyroslyakov.github.io/gta67/)

Автономная городская миниатюра в стеклянном кубе. Стрелки или перетаскивание вращают камеру. Колесо, щипок или кнопки меняют масштаб. Двойной щелчок приближает выбранную улицу. Home возвращает общий вид.

Главная сцена — `cube/quarter.tscn`. Геометрия и движение создаются в Godot. Отдельные ресурсы POLYGON для этой сцены не требуются. Игровая версия с управлением персонажем живёт в ветке `3.0`.

Сайт в `docs/` собирается командой `godot --headless --export-release Web docs/index.html` с установленным шаблоном Web для Godot 4.7.2. Локальный запуск — `python3 -m http.server 8000 --directory docs`. Исходный HTML находится в `cube/site.html`.
